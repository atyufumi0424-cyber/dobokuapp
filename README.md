# 土木図面 数量拾いAI MVP

スマホでも扱いやすい Streamlit ベースの土木図面数量化アプリです。

## 現在できること

- PDF / PNG / JPG 図面のプレビュー
- 図面中の線分候補を検出し延長(m)へ換算
- 閉領域候補を検出し面積(m²)へ換算
- 検出面積と入力した平均厚・深さから以下を算出
  - 掘削量(m³)
  - 盛土量(m³)
  - 舗装材量(m³)
  - 路盤材量(m³)
  - コンクリート量(m³)
- CSV数量表出力
- 図面なしでも「サンプル図面」でスマホ画面を確認可能

## スマホ向けUI

- 縦画面ではカラムを1列化
- ボタンを大きく表示
- 図面プレビューを画面幅いっぱいに表示
- 詳細設定は折りたたみ

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 公開について

GitHub Pagesでは `index.html` のスマホ向けUIプレビューを公開できます。
実際にPDFや画像を解析するPython本体は、Streamlit Community CloudなどのPython実行環境へのデプロイが必要です。

## 次の実務版候補

道路・造成・外構図面を対象に、道路中心線、側溝、縁石、擁壁、集水桝、マンホール、法面、区画線などを工種別にAI検出し、検出箇所を図面上で色分けして数量表へ自動反映する構成が次の段階です。

## 注意

本MVPの検出結果は候補値です。積算・施工数量として使用する場合は必ず図面・現場条件と照合してください。画像写真は縮尺換算の誤差が大きくなるため、PDF図面推奨です。
